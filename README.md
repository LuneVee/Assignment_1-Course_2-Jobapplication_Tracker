About this Project:
This project is designed to make it easier to store, manage, and view jobapplications. You can add new jobapplications, browse existing entries, and access different types of information about each jobapplication.

How to run Program:
Currently, I am experiencing some issues with building and publishing this project. However, you can still run it using Visual Studio or another development environment that supports C#.
To get started, download the project files from GitHub. You can either download them as a ZIP file or clone the repository directly into Visual Studio.
Once you have the files, open the project in your preferred C# development environment and run it. A console menu will appear on your screen, allowing you to navigate the program by entering either a number or a text command, depending on the available options.
From there, simply follow the instructions displayed in the console and respond to the prompts to explore and use the program's features.
